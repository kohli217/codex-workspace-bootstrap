# Support

## Questions and usage problems

Open a GitHub issue when you have a reproducible problem with the CLI. Please include:

- operating system;
- Python version;
- the command you ran;
- the smallest safe reproduction you can provide;
- expected and observed behavior.

Do **not** include credentials, tokens, private repository contents, or secret values.

## Feature requests

Use the feature request issue template and describe the maintainer workflow or developer problem you want to solve.

## Security-sensitive reports

Follow [SECURITY.md](SECURITY.md). Do not disclose exploit details or credentials in a public issue.

## Scope

This is a small community-maintained open-source project. Support is best-effort and there is no guaranteed response time.
