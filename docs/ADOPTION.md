# Adoption and usage reports

This project does not claim adoption that cannot be verified.

If you use `codex-workspace-bootstrap` in a public or private project, you can help improve it by opening a **Usage report** issue.

Useful reports include:

- operating system and shell;
- repository language or toolchain;
- whether you use the CLI, GitHub Action, or both;
- which checks were useful or noisy;
- whether generated `AGENTS.md` guidance needed changes;
- feature requests discovered through real use.

Do not include credentials, private repository contents, secret values, or proprietary source code.

## Public usage references

When a user explicitly provides permission and a public reference, this document may link to that repository or report.

There are no fabricated logos, testimonials, download counts, or usage claims in this project.
